# Verba — releases

Release feed for **Verba**, the global (EN-first) sibling of
[Поток](https://github.com/karpovantonme/potok-releases): a macOS
menu-bar dictation app. DMG assets live in GitHub Releases;
`appcast.xml` is the Sparkle update feed baked into every build.

Install: download the latest `Verba-X.Y.Z.W.dmg` from Releases,
drag Verba.app to Applications. Updates: Verba → «Check for updates…».
